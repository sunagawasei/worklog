# worklog-find — 過去タスク検索・再開スキル

## 使用方法

```
/worklog-find <キーワード> [キーワード2 ...]
```

例:
- `/worklog-find perman`
- `/worklog-find perman 棚卸し`

## 重要な不変条件

- **検索はファイル名のみ**。ログの内容（開始・停止時刻）は検索しない
- **タグ名解決は `worklog tag list --json` から取得**する。IDをそのまま表示しない
- **再開時は現在稼働中のタスクが自動停止される**。事前に `worklog status --json` で確認すること

## ワークフロー

### Step 1 — キーワードの確定

引数で渡されたキーワードをそのまま使用する。  
引数が一つもない場合のみ `AskUserQuestion` で検索ワードを尋ねる。

### Step 2 — 過去タスクを検索

キーワードごとに以下を実行し、結果をマージして重複を除去する:

```bash
.claude/scripts/find-past-project.sh "<keyword>"
```

出力形式（タブ区切り、新しい順）:
```
2026-05-18	PERMANマシンユーザー棚卸し	14
2026-03-16	perman棚卸し	14
```

複数キーワードの場合、同じ `日付+プロジェクト名` の組み合わせは1件に絞る。

### Step 3 — タグ名を解決して結果を表示

```bash
worklog tag list --json
```

取得したタグ一覧でタグIDを名前に変換し、以下の形式でユーザーに提示する:

```
# 検索結果: "perman"

1. 2026-05-18  PERMANマシンユーザー棚卸し  (others)
2. 2026-04-20  perman棚卸し                (others)
3. 2026-03-16  perman棚卸し                (others)
...
```

件数が0件の場合はその旨伝えてスキルを終了する。

### Step 4 — 再開するか確認（任意）

`AskUserQuestion` で次の質問を提示する:

- **質問**: 「このタスクを今すぐ開始しますか？」
- **選択肢**: 結果の上位3件のプロジェクト名 + 「開始しない」（4択）
- 件数が3件未満の場合は件数分の選択肢 + 「開始しない」

「開始しない」が選択された場合はスキルを終了する。

### Step 5 — タスクを開始

選択されたタスクのプロジェクト名とタグIDを使って開始する:

```bash
worklog new "<プロジェクト名>" <タグID>
```

現在稼働中のタスクがある場合は `switch` と同じ動作（自動停止→開始）になるため、
Step 4 前に `worklog status --json` で確認し、稼働中タスクがあればユーザーに通知すること。
